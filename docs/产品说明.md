# 企业客服知识库系统 · 产品说明

> 本文档面向非技术读者，说明这套系统解决什么问题、谁来用、怎么用，以及它的能力边界。

## 一、解决什么问题

中小企业客服常见三个痛点：

1. **重复问题多**：退换货、发票、物流等问题每天被反复询问，占用大量人力。
2. **知识散落**：答案散落在 Word、PDF、表格里，新客服上手慢，回答口径不统一。
3. **直接用 ChatGPT 不可靠**：通用大模型不了解公司政策，容易「一本正经地编造」。

本系统把公司的文档变成一个「只有 AI 客服能查阅的资料库」：客户提问时，AI 先从资料库里检索相关内容，**只依据检索到的内容回答，并注明出处**；资料库里没有的，就老实说找不到、建议转人工。

## 二、角色与使用流程

### 管理员（如客服主管）

1. 注册账号（第一个注册的账号自动成为管理员）。
2. 进入「知识库管理」，上传公司的政策文档（PDF / Word / TXT / Markdown），系统自动解析并建立检索索引。
3. 在「用户管理」查看注册情况，把需要维护知识库的同事设为管理员。

### 普通用户（员工或客户）

1. 注册并登录，进入「客服问答」。
2. 像聊天一样提问，例如「支持七天无理由退货吗」；可以继续追问「那运费谁出」，系统理解上下文。
3. 每个回答下方会标注**参考来源**（来自哪份文档），可点击「有帮助 / 没帮助」反馈。
4. 「历史记录」里可随时回看过去的问答，支持搜索和删除。

## 三、功能清单

| 模块 | 功能 |
|---|---|
| 账号 | 注册、登录、退出；管理员 / 普通用户两种角色 |
| 知识库（管理员） | 多文件上传、自动解析索引、状态跟踪（可用 / 处理中 / 失败及原因）、删除、一键重建索引 |
| 智能问答 | 多轮对话、引用来源、找不到依据时转人工提示、点赞点踩 |
| 历史记录 | 本人会话列表、关键字搜索、查看、删除 |
| 管理后台（管理员） | 数据看板（用户 / 文档 / 会话 / 消息数）、用户角色管理 |
| 部署 | 支持 Docker 一键部署，数据持久化，重启不丢失 |

## 四、边界与不足

- **只回答知识库里有的内容**：知识库为空或未覆盖的问题，系统不会编造，只会提示联系人工客服。
- **扫描版 PDF 不支持**：图片型 PDF 无法提取文字，请上传可复制文本的文件。
- **单知识库**：目前全公司共享一个知识库，暂不支持按部门隔离多个知识库。
- **无人工转接**：暂未对接在线客服系统，仅给出「建议联系人工客服」的提示。
- **回答非实时流式**：回答需等待数秒生成，暂不支持逐字输出。
- **文件上限**：单个文档不超过 20MB。

## 五、后续可扩展方向

- 对接微信公众号 / 网页在线客服插件，让客户在常用渠道直接提问。
- 人工转接与工单系统联动。
- 回答流式输出（打字机效果），提升体验。
- 多知识库隔离（按部门 / 产品线），细粒度权限。
- 知识条目审核与版本管理、无效知识自动下线。
- 接入 rerank 重排序模型与评测集，持续提升回答准确率。
